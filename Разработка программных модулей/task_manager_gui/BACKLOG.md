# BACKLOG — история версий Task Manager

## v0.0.1
Разработан цикл приложения (структурное программирование). Меню в бесконечном цикле `while`, выбор пункта через `match-case`.

## v0.0.2
Внедрен i/o функционал для ввода задачи: пользователь вводит текст, задача попадает в список.

## v0.0.3
Разработаны функции для цикла (функциональное программирование): вывод списка и меню вынесены в функции.

## v0.0.4
Добавлены проверки и подтверждения: номер задачи проверяется на число и на попадание в диапазон списка (`check_confirm`).

## v0.0.5
Созданы методы сохранения и загрузки (файловые сохранения): задачи пишутся в `saves.txt` и читаются при запуске.

## v0.0.6
Созданы методы для удаления, редактирования и создания задач, логика вынесена из цикла.

## v0.0.7
Основной цикл помещен в отдельный метод `main`, вызов в конце скрипта под `if __name__ == "__main__"`.

## v0.0.8
Реализован функционал добавления контента задачи: имя + содержание.

## v0.0.9
Код разбит на модули `config`, `core`, `utils`, `view`, `storage`, `main`. Добавлены `BACKLOG.md` и `BUGFIX.md`, приложение протестировано, найдено 8 багов.

## v0.1.0
Исправлены все 8 багов консольной версии: проверка пустого ввода при редактировании, сохранение формата задачи, безопасная проверка номера, очистка пробелов в меню, пропуск пустых строк при загрузке, путь к файлу не зависит от папки запуска, одно сообщение об ошибке, защита от пустого списка.

## v0.1.1
Функция `get_base_dir()` определяет папку запуска (в том числе для exe), функция `insure_save_file()` создает файл сохранений при первом запуске. Проект собран в exe командой `pyinstaller --onefile main.py`.

## v0.1.2
Начат графический интерфейс на Tkinter: пакет `src`, окно `root` с кнопкой и надписью, размер, заголовок и иконка. Класс `Interface` создает главный объект `root` в методе `__init__`.

## v0.2.0 (эта версия)
Графическое приложение со слоистой архитектурой:
- **Сохранение в JSON.** Файл `saves.txt` заменен на `tasks.json`. Задача хранится как словарь `{"name": ..., "content": ...}`, а не как строка `имя | содержание`. Запись идет через временный файл и `os.replace`, поэтому сбой записи не портит старые данные. Поврежденный файл не роняет приложение: его копия сохраняется как `tasks.json.broken`, программа стартует с пустым списком и показывает сообщение.
- **Слои.** `storage.py` (хранение), `core.py` (логика без Tkinter: добавить, изменить, удалить), `view.py` (показ задач), `Interface.py` (окно, связывает слои), `main.py` (точка входа), `config.py` (настройки).
- **Собственные виджеты.** `AppButton.py` (кнопка с общим видом), `AppLabel.py` (надпись со статусом: обычный, успех, ошибка), `AppListbox.py` (список с полосой прокрутки и методами `set_items`, `selected_index`, `select`).
- **Показ задач.** Метод `show_tasks` в `view.py` выводит задачи в `AppListbox`, счетчик «Всего задач» выводится через `AppLabel`.
- **Удобство.** Выбор задачи в списке подставляет ее данные в поля ввода, после изменения выделение сохраняется, удаление просит подтверждение, статус действия виден внизу окна.
- **Проверки.** Пустое название или содержание, слишком длинный текст (название до 50, содержание до 200 символов), изменение или удаление без выбранной задачи.
