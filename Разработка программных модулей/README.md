# Разработка программных модулей

| Папка | Что внутри |
|-------|------------|
| `task_manager/` | Task Manager: модули config, core, utils, view, storage, main; папка `src` с окнами Tkinter (interface, calculator, pattern); BUGFIX.md и BACKLOG.md |
| `task_manager_gui/` | Task Manager с окном Tkinter и слоистой архитектурой: Interface, view, storage (JSON), core, свои виджеты AppButton, AppLabel, AppListbox; BACKLOG.md и BUGFIX.md |
| `systen_v1/` | Ранняя версия Task Manager в одном файле (`systen.py` использует `processes.py`) |
| `ООП/` | Классы Animal, Cat, Dog |
| `document/` | Первый BACKLOG.md и учебный скрипт |
| `python_ars/` | Черновик меню на Tkinter |
| `scripts/` | Отдельные учебные скрипты |
