# BUGFIX — проблемы, защита и возможные улучшения

## 1. Что защищено в версии 0.2.0 (проверено тестами)

Приложение проверено 28 сценариями на настоящем окне (ввод, нажатия кнопок, перезапуск). Все проходят.

| № | Возможная проблема | Как закрыта |
|---|--------------------|-------------|
| 1 | Пустое или состоящее из пробелов название и содержание | `core.make_task` отклоняет ввод, введенный текст остается в полях |
| 2 | Слишком длинный текст ломает показ списка | Лимиты 50 и 200 символов (`config.py`) |
| 3 | Нажатие «Изменить» или «Удалить» без выбранной задачи | Сообщение «Выберите задачу в списке!», данные не меняются |
| 4 | Случайное удаление | Окно подтверждения; при отмене задача остается |
| 5 | Выделение пропадает, когда фокус уходит в поле ввода | У `AppListbox` включен `exportselection=False` |
| 6 | Файл `tasks.json` испорчен или имеет неверную структуру | Копия сохраняется как `tasks.json.broken`, приложение стартует с пустым списком и показывает ошибку |
| 7 | Сбой во время записи теряет все задачи | Запись во временный файл и `os.replace` |
| 8 | Первый запуск без файла сохранений | `insure_save_file` создает `tasks.json` |
| 9 | Кавычки, слэши, кириллица в тексте | JSON с `ensure_ascii=False` и кодировкой UTF-8, проверено перезапуском |

## 2. Особенности и известные ограничения

- После добавления новая задача выделяется в списке, поэтому «Изменить» сразу после «Добавить» правит именно ее (поля при этом пустые, и приложение сообщит об ошибке).
- Старые задачи из `saves.txt` консольной версии не переносятся в `tasks.json`.
- Две одновременно запущенные копии приложения не знают друг о друге: сохраняет та, что закрывается или меняет данные позже.
- Иконка окна ищется рядом с программой; при сборке в exe файл `icon.ico` нужно добавлять отдельно (`--add-data`). Если иконки нет, окно просто открывается без нее.

## 3. Возможные улучшения и изменения (не реализованы)

**Функции задач**
- Отметка «выполнено» (флажок или зачеркивание текста).
- Срок выполнения и сортировка по сроку.
- Приоритет задачи и цветовые метки.
- Поиск и фильтр по тексту и по статусу.
- Категории и теги.

**Удобство интерфейса**
- Двойной щелчок по задаче открывает редактирование.
- Горячие клавиши: Enter добавляет, Delete удаляет, Ctrl+Z отменяет.
- Отмена и повтор действий (undo, redo).
- Перетаскивание задач для изменения порядка.
- Выбор нескольких задач для удаления.
- Тёмная тема и настройка размера шрифта.
- Окно подтверждения только для важных действий, с пунктом «больше не спрашивать».

**Данные и архитектура**
- Перенос старых задач из `saves.txt` при первом запуске.
- Хранение в SQLite вместо JSON (поиск и сортировка средствами БД).
- Резервные копии `tasks.json` по расписанию.
- Экспорт и импорт задач (CSV).
- Блокировка при запуске второй копии приложения.
- Логирование ошибок в файл.

**Качество и сборка**
- Автотесты `pytest` для `core` и `storage` (слой логики не зависит от Tkinter, его легко тестировать).
- Сборка в один exe с иконкой через PyInstaller.
- Единый файл с настройками пользователя (размер окна, тема).
