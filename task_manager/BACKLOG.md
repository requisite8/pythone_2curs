# BACKLOG — история версий Task Manager

## v0.0.1
Разработан цикл приложения (структурное программирование). Меню в бесконечном цикле `while`, выбор пункта через `match-case`.

## v0.0.2
Внедрен i/o функционал для ввода задачи: пользователь вводит текст, задача попадает в список.

## v0.0.3
Разработаны функции для цикла (функциональное программирование): вывод списка и меню вынесены в функции.

## v0.0.4
Добавлены проверки и подтверждения: номер задачи проверяется на число и на попадание в диапазон списка (`check_confirm`).

## v0.0.5
Созданы методы сохранения и загрузки (файловые сохранения): задачи пишутся в `saves.txt` и читаются при запуске.

## v0.0.6
Созданы методы для удаления, редактирования и создания задач, логика вынесена из цикла.

## v0.0.7
Основной цикл помещен в отдельный метод `main`, вызов в конце скрипта под `if __name__ == "__main__"`.

## v0.0.8
Реализован функционал добавления контента задачи: имя + содержание (формат `имя | содержание`).

## v0.0.9
Код разбит на модули: `config` (общие данные), `core` (добавление, редактирование, удаление), `utils` (проверки), `view` (вывод в консоль), `storage` (сохранение и загрузка), `main` (точка входа). Добавлены `BACKLOG.md` и `BUGFIX.md`, приложение протестировано, найдено 8 багов.

## v0.1.0
Исправлены все 8 багов из `BUGFIX.md`: проверка пустого ввода при редактировании, сохранение формата `имя | содержание`, безопасная проверка номера задачи, очистка пробелов в меню, пропуск пустых строк при загрузке, путь к `saves.txt` не зависит от папки запуска, одно сообщение об ошибке при удалении, защита от пустого списка. В `main.py` добавлен docstring с описанием улучшений по версиям.
