# Раздел 1. Основы проектирования баз данных — уроки 5-6

ER-диаграмма базы данных учебного центра **Top Academy**, построенная в draw.io
(файл `top_academy_db.drawio` — открывается на [app.diagrams.net](https://app.diagrams.net) через File → Open From → Device).

## Сущности

| Таблица | Назначение |
|---|---|
| Filials | филиалы центра |
| Courses | курсы обучения |
| Teachers | преподаватели |
| Groups | учебные группы (курс + преподаватель + филиал) |
| Students | студенты |
| Enrollments | зачисление студента в группу |
| Payments | оплаты студентов |
| Classrooms | аудитории филиала |
| Lessons | занятия группы в конкретной аудитории |
| Attendance | посещаемость занятий |
| Homeworks | домашние задания по занятию |
| Grades | оценки студентов за домашние задания |
| Certificates | сертификаты об окончании курса |
| Staff | административный персонал филиала |

Каждая таблица имеет первичный ключ `id` (PK), внешние ключи помечены `FK`
и связывают дочернюю (много) сторону с родительской (одна) сущностью
(например, `Groups.course_id → Courses.id`).
