# Основы проектирования баз данных

| Папка | Что внутри |
|-------|------------|
| `db_top_academy/` | ER-диаграмма Top Academy для draw.io |
| `db_youtube/` | SQL-скрипт схемы YouTube для SQLite (28 таблиц, только PK и FK) |
| `db_college/` | SQL-скрипт схемы колледжа для MySQL |
| `academy/` | SQL-скрипт схемы Academy для MySQL Workbench (8 таблиц, FK, запрос в конце) |
